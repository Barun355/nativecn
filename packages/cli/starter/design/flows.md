# User Flows

Confirmed User Flows, one per section, in plain language. Your agent derives them
from the code and asks you to confirm or correct them before saving them here.
The Visual QA Loop (`nativecn-visual-qa`) checks each flow end to end.

## Example: Sign in

1. Open the app on the Welcome Screen.
2. Tap "Sign in": the Sign in Screen opens.
3. Enter email and password, then tap "Continue": the Home Screen opens.

# Expectations

What a Screen should look like or do, for Screens without a reference image.
Reference images (e.g. Figma exports) go in `design/screens/` as `<screen>.png`,
plus `<screen>.dark.png` for dark mode.

## Example: Home

- Shows a greeting with the user's first name as the title.
- Lists recent items as Cards; an empty state appears when there are none.
- The primary Button ("New item") sits at the bottom, above the safe area.
